# Robinhood Pools Observatory

Robinhood Chain 流动性池、LP 地址研究和公开资金流前端。

- 数据接口：[`https://rhpools.lol`](https://rhpools.lol)
- 上游项目：[`wock9000/robinhoodpools`](https://github.com/wock9000/robinhoodpools)
- 在线站点：[`https://ptert.github.io`](https://ptert.github.io)

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run build:pages
```
